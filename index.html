GRIN miniscope: 1:1 relay for fluorescence imaging

A miniature fluorescence microscope optical system designed and optimized in Ansys Zemax OpticStudio.

I designed and optimized a miniature fluorescence microscope (miniscope) optical system built from multiple GRIN (gradient-index) rod lenses. The lenses are cascaded into a superposition compound system, and the layout is designed to accommodate dichroic mirrors and excitation/emission filters. The goal is to maximize the usable field of view while minimizing Seidel aberrations.

Tool

4 GRIN rods

Why GRIN lenses

GRIN rod lenses focus light through a smoothly varying refractive index inside the glass, so they have flat entrance and exit faces. That makes them very compact, easy to mount and stack, and a natural fit for a head-mounted miniscope, where size and weight are tightly constrained.

System architecture

  • Cascaded GRIN relay. Several GRIN rod lenses are arranged as a superposition compound system. Each segment relays the image onward, so the optical path can be extended while the overall magnification stays at 1:1.
  • Dichroic mirror. The design leaves room for a dichroic mirror that separates the excitation light from the emitted fluorescence between the lenses.
  • Excitation and emission filters. Filters isolate the excitation band from the fluorescence signal so that only the emission reaches the detector.
  • Two-field model. The system is evaluated on-axis and at a 1 mm object height, which shows how performance degrades toward the edge of the field.

Design goals and optimization

The main trade-off in this design is field of view versus aberration. A wider field is more useful for imaging, but off-axis rays push the Seidel aberrations (spherical aberration, coma, astigmatism, field curvature, and distortion) up quickly. My workflow:

  • Set up the prescription in sequential mode with the GRIN rod lenses, and trace both fields at 0.53 µm.
  • Define merit function targets for unit magnification and a small spot at the image plane.
  • Iterate on lens spacing and focus positions, and test how small shifts of individual surfaces affect the on-axis and off-axis spots.
  • Check the front of the first lens for vignetting. A few marginal rays were clipped there, so I worked on trimming them out of the beam.

Results so far

0.238 µmRMS spot radius, on-axis
12.84 µmRMS spot radius, 1 mm field
0.996 mmimage height for a 1.000 mm object

On-axis performance is essentially diffraction-limited, and the image height is within half a percent of the object height, so the relay is very close to true 1:1. The off-axis field is the weak point. Its spot is larger and elliptical, which points to residual astigmatism and field aberrations, and that is where my current optimization effort is focused.

Next steps

  • Reduce the off-axis spot size while holding the on-axis performance.
  • Extend the evaluated field of view beyond 1 mm.
  • Run a tolerance analysis on spacing, tilt, and index errors.

Design notes

The workflow I follow, and a place for write-ups.

  1. Specify

    Wavelength, NA, field, magnification, and package size.

  2. Model

    Set up the system in Zemax OpticStudio and trace on-axis and off-axis fields.

  3. Optimize

    Tune merit-function targets and watch for vignetting and aberrations.

  4. Tolerance

    Check how spacing, tilt, and index errors move performance.

  5. Build and test

    Verify on the bench and compare against the model.
